Run the tests through `python "{{room_py}}" check` from your worktree: it runs `{{test}}` under a lock so parallel workers take turns, and exits with that command's code. If it exits 3 (`suite lock busy`), another run is still going; if it exits 3 with `suite ran out of time`, the suite didn't finish in the limit. Either way exit 3 means `TESTS: INCOMPLETE` / `REVIEW: INCOMPLETE`, never FAIL: say so, and don't count it as a test failure.
