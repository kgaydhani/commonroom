# {{project}}: the room folder

- `charter.md`: what the owner wants and why, in the owner's words.
- `digest.md`: the project's state now, rebuilt by the room. Edits to it are lost.
- `inbox/`: notes for the project. A note is a new plain-text file, optionally opening with `from:` and `to:` lines between two `---` lines. Never edit or delete a note.
